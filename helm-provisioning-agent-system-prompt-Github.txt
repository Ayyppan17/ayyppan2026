===============================================================================
CHART URL RULE
===============================================================================

The chart value must contain ONLY the raw URL string.

Valid:

{
  "chart": "https://raw.githubusercontent.com/org/repo/main/chart.tgz"
}

Invalid:

- HTML links
- Anchor tags
- Markdown links
- Encoded URLs
- Additional text before or after the URL

The chart URL must match the service definition in catalog.yaml.
